ThatFlag 개인정보 처리방침

시행일: 2026년 9월 18일 · 운영: Indie-Hackerz (ThatFlag)

ThatFlag(이하 “앱”)는 현재 위치에 깃발을 저장하고 다시 찾도록 안내하는 유틸리티 앱입니다. 본 방침은 개인정보 보호법 및 위치정보의 보호 및 이용 등에 관한 법률에 따라, 앱이 어떤 정보를 어떻게 다루는지 설명합니다.

1. 처리 목적

깃발 저장 및 찾기(거리·나침반 안내) 서비스 제공.

2. 처리 항목

  • 개인위치정보: 좌표·정확도
  • 깃발 이름·메모, 선택한 사진(선택)
  • 기기 권한 상태: 위치·사진 등 기능 제공을 위한 권한 처리

계정, 광고 식별자, 분석 SDK, 저희 서버로의 업로드는 현재 사용하지 않습니다. 쿠키·광고 ID 등 자동수집장치는 해당 없습니다.

3. 처리·보유 기간

  • 기기 내 앱 저장소에 이용자가 삭제하거나 앱을 삭제(또는 로컬 데이터 초기화)할 때까지 보유합니다.
  • 저희 서버에 이용자 데이터를 보관하지 않으므로 서버 보유 기간은 없습니다.

4. 개인위치정보·백그라운드 위치

  • 개인위치정보는 깃발 저장·찾기에만 사용합니다.
  • 찾기를 켠 동안에는 앱이 화면에 없어도 백그라운드 위치를 사용할 수 있으며, 잠금 화면·Live Activity·진행 중 알림에 거리·방향 등이 표시될 수 있습니다. 찾기를 끄면 해당 목적의 위치 사용을 중지합니다.
  • 서버가 없어 「개인위치정보의 수집·이용·제공사실 확인자료」는 생성·보유하지 않습니다.

5. 제3자 제공·처리위탁

  • 기본 찾기 기능은 인터넷 없이 기기 센서만으로 동작합니다.
  • 사용자가 “지도에서 열기”를 선택할 때만 저장 좌표가 설치된 지도 앱 또는 지도 웹페이지로 전달될 수 있으며, 이때 해당 지도 서비스의 약관·개인정보 처리방침이 적용됩니다.
  • 그 외 제3자 제공, 처리위탁, 판매·임대는 하지 않습니다.

6. 가명정보·민감정보

가명정보 처리 및 민감정보 수집은 해당 없습니다. (선택 사진은 이용자가 깃발 기록 목적으로 직접 추가하는 일반 콘텐츠입니다.)

7. 파기 절차·방법

  • 개별 깃발 삭제 시 해당 사진·메모·좌표를 앱 저장소에서 삭제합니다.
  • 앱 삭제 또는 로컬 데이터 초기화 시 앱이 보관한 로컬 데이터를 삭제합니다.
  • 서버 보관 데이터가 없어 서버 파기 절차는 없습니다.

8. 정보주체 권리·행사 방법

  • 열람·삭제: 앱 내 깃발 목록에서 확인·삭제
  • 동의 철회·권한 변경: 기기 설정 → 앱 → ThatFlag → 권한
  • 전체 삭제: 로컬 데이터 초기화 또는 앱 삭제
  • 정밀 위치 권한을 거부하면 핵심 저장·찾기 기능을 사용할 수 없습니다.

9. 안전성 확보조치

온디바이스 저장, 저희 서버로의 미전송, 기기·클라우드 백업 제외 구성을 기본으로 합니다. (기기 OS·앱스토어 보안 환경에 의존합니다.)

10. 국외 이전·국외 직접수집

저희가 이용자 데이터를 국외 서버로 이전하거나 국외에서 직접 수집하지 않습니다. 사용자가 지도를 열 때 좌표가 해외 지도 서비스로 전달될 수 있으며, 그 처리는 해당 서비스 정책에 따릅니다.

11. 아동·보호의무자

앱은 아동을 대상으로 하지 않으며, 14세 미만 아동의 개인위치정보·개인정보를 고의로 수집하지 않습니다. 보호의무자 동의 절차는 해당 없습니다.

12. 방침 변경

중요한 변경이 있으면 앱에서 새 버전으로 다시 동의를 요청하거나 본 페이지를 갱신합니다. 시행일은 상단에 표시합니다. 본 페이지는 Cloudflare Pages 등 공개 URL로 상시 게재합니다.

13. 개인정보·위치정보 고충 처리 / 책임자

개인정보 보호 및 위치정보 관리 관련 고충·문의는 GitHub 저장소 Indie-Hackerz/thatflag 이슈로 남겨 주세요. (연락용 이메일·성명은 추후 본 페이지에 추가할 수 있습니다.)

본 문서는 앱 스토어 등록을 위한 공개 안내이며, 개별 법률 자문을 대체하지 않습니다. LBS 사업자 신고·별도 약관 해당 여부는 별도 검토 사항입니다.
